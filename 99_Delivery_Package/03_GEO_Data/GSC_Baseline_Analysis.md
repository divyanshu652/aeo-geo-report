## 10. GSC REPORTING LIMITATIONS

**Important:** GSC only shows the top 1,000 queries per property. The actual query count is likely much higher. The 962 zero-click queries in this dataset represent only the top 1,000 by impressions — there are likely thousands more long-tail queries generating impressions that aren't visible in this report.

Also note: **Queries.csv** shows 259 total clicks, while **Chart.csv** shows 471 total clicks. This discrepancy may be due to:
- Different reporting timeframes
- Queries.csv showing only top 1,000 queries
- Chart.csv capturing all traffic (including queries below the 1,000 threshold)
